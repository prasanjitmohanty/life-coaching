# Swarnlata life coaching

A responsive, single-page website made with HTML, CSS, and original SVG artwork. No JavaScript, packages, build step, external fonts, analytics, or backend are required.

## View locally

Open `index.html` directly in a browser, or serve this directory with any static file server. For example, with Python 3 installed:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`. Deploy the directory unchanged to a static host such as GitHub Pages; keep the `assets` directory beside `index.html`.

## Before publishing for enquiries

The site deliberately does not invent a biography, credentials, testimonials, prices, contact details, or a booking service. The contact section and final FAQ explicitly say enquiries are not open.

Confirm the copy and coaching focus areas with Swarnlata. Once verified contact information is available, update `#next-step` and the enquiry FAQ together. Replace the coming-soon notice with a genuine email or scheduling link, and confirm any session format, availability, and fees before publishing them. There is no form that pretends to send messages.

## Design and accessibility

The design uses an ivory, forest, sage, and terracotta palette, system sans-serif and Georgia typography, and original landscape/leaf artwork instead of an invented portrait. Internal section links work without JavaScript. FAQs use native `details`/`summary`; keyboard focus, a skip link, reduced-motion preferences, mobile layouts, and print styles are supported.

The supplied text-extract analysis of the four reference websites informed the content structure: empathetic entry points and clear service areas from lifecoachramandiep.com, specificity and a short process from shipraojha.com, strengths-oriented reflection from abhilashadwivedimetamind.com, and concise benefit-led sections from coachswami.com. This is not a visual reproduction. No reference text, portraits, testimonials, credentials, or commercial promises are reused.
